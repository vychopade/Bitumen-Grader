Hey. This is BitumenGrader. You give it photos of froth or bitumen samples and it estimates three numbers: water percent, solids percent, and bitumen percent. It is a quick look from a picture, not a replacement for the lab.

From the project folder run pip install -r requirements.txt. That pulls in PyTorch, the desktop UI, and the image libraries. Then run python main.py. The window has Train, Grade, and Models. Train is where you load a labels file (Image, Pan, Water, Solids, Bitumen) and a folder of matching photos. Grade is where you drop new photos once a model is loaded. Saved checkpoints land in models/.

To swap the CNN, open config.py and change ACTIVE_MODEL. It is just a string. Set it to a name that exists in MODEL_REGISTRY in models/__init__.py, for example cnn_basic. That is the only line you need to edit. If you write a new network, register it in that dictionary first, then point ACTIVE_MODEL at it.

Put sample photos in their own folder, jpg png or tif is fine, nested folders are okay. On the Train page, point the app at that folder plus your labels table. The Image column should match the file names.

The three outputs are percentages. They should add up to about 100. If they are off by more than a few percent, treat that photo as shaky. R squared on a saved model is how well it tracked the lab labels. Closer to 1 is better. Zero is no better than guessing the average. Negative means it did worse than that. MAE is the typical error in percentage points, so smaller is better.

If something will not start, you are probably not in the project folder or the pip install did not finish. Training is slow on CPU. That is normal.
