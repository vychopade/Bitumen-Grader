  BITUMENGRADER — USER GUIDE
════════════════════════════════════════════════════════

1. WHAT IT DOES
---------------

BitumenGrader looks at photos of bitumen samples and predicts three
percentages: Water, Solids, and Bitumen.

You train a model on photos that already have lab labels, then use that
model to grade new photos. It won't replace a full lab test, but it's a
fast way to get a repeatable estimate from a picture.

Predictions also show a sum check (Water + Solids + Bitumen should be
near 100%) and a rough Pan grade based on the Bitumen value.


2. INSTALL AND RUN
------------------

You need:
  - Python 3.9+
  - Windows 10/11, macOS 11+, or a recent Linux
  - A few GB of free disk space (PyTorch is big) and ideally 4 GB+ RAM

Install dependencies once:

    pip install -r requirements.txt

Start the app:

    python main.py

You should see four sidebar pages: Import Images, Train Model,
Grade Images, and Model Library.

To run the offline tests (or build a packaged app):

    pip install -r requirements-dev.txt
    python -m pytest tests/smoke_test.py -v
    pyinstaller BitumenGrader.spec

A packaged app saves models in the OS application-data folder
(macOS: ~/Library/Application Support/BitumenGrader/models,
Windows: %APPDATA%\BitumenGrader\models,
Linux: ~/.bitumengrader/models).
When you run from source, models stay in the project's models/ folder.


3. GRADE IMAGES (EXISTING MODEL)
--------------------------------

1. Open Model Library and click Load Model on the card you want.
2. Go to Grade Images.
3. Add photos (Add Images, or drag and drop). JPG, PNG, and TIF work.
4. Click Grade All, or pick one image and click Grade This Image.
5. Check the results:
   - Water / Solids / Bitumen percentages
   - Sum row: green if close to 100%, amber if a bit off, red if more
     than about 5% off
   - Closest Pan grade (rough, from Bitumen %)
6. Export CSV if you want a spreadsheet of the batch.
7. Clear Results (or Clear All) when you're done with that batch.


4. TRAIN A NEW MODEL
--------------------

You need:
  - A CSV/Excel file with columns: Image, Pan, Water, Solids, Bitumen
    (Image = filename; extension optional). An optional Campaign / Experiment /
    Run column is used if you pick the experiment hold-out split.
  - A folder of those photos
  - Ideally 50+ images per Pan grade (200+ is better). Mix lighting and
    framing a bit so the model isn't too picky later.

Steps:
1. Train Model → load the labels file (drop zone or Browse).
2. Select the image folder. Check the match summary; fix unmatched names
   if the match rate is low.
3. Review the dataset summary (train / validation / test counts, ranges,
   Pan distribution, and campaigns if you use experiment hold-out).
4. Name the model. Leave Architecture on Baseline CNN unless you have a
   reason to try ImageNet transfer (mainly for Solids).
5. Optional: check "Continue training a saved model" to keep training an
   existing checkpoint on this new dataset. That saves a new model and
   leaves the original in the library.
6. Start Training. Watch loss/MAE charts and the log. You can Stop
   Training anytime; the best checkpoint so far is kept.
7. When it finishes, the model is saved and set as active. Go grade
   some photos to try it.

The default is a compact CNN trained from scratch on froth photos. That
is more robust on this kind of image than starting from ImageNet. ResNet50
and VGG16 transfer are optional second-stage experiments; compare them to
the baseline with an experiment hold-out split before you rely on them.


5. TRAINING SETTINGS
--------------------

Only a few choices are on the Train page. Everything else is locked to the
recipe from the froth-image study.

  Architecture (default Baseline CNN)
    Baseline CNN is trained from scratch and is the safest default.
    ResNet50 / VGG16 start from ImageNet and are optional. Transfer helped
    Solids in some setups and usually did not help Bitumen.

  Adaptation (ResNet50 / VGG16)
    Fine-tune trains the whole net (recommended; won the study's useful
    transfer runs). Frozen features keep the ImageNet backbone fixed and
    were weaker, especially for Bitumen.

  Head (ResNet50 / VGG16)
    Native = one linear layer. 2-layer (C2) is the custom head that helped
    Solids. Deeper batch-norm heads are not offered; they collapse.

  Split (default Random)
    Random split measures interpolation within familiar runs. Experiment
    hold-out keeps whole flotation campaigns (from the filename, e.g. N12,
    or a Campaign column) out of training — closer to a new plant run.

  Continue training a saved model
    Loads that checkpoint and trains it further on the labels/folder you
    pick. Architecture and head stay locked. A new file is saved.

  Epochs (default 100)
    How many full passes over the training images. Early stopping will
    halt sooner if validation stops improving for 10 epochs.

Fixed behind the scenes (not shown in the UI):

  Batch size 32, Adam, weight decay 0.0001
  Learning rate 0.0001 (baseline / fine-tune) or 0.001 (frozen features)
  Validation 20% / test 15%
  Images resized to 256×256 (legacy ResNet-18 stays at 224)
  Targets normalised, cosine LR schedule, composition sum penalty
  Transfer models start from ImageNet weights


6. EDITING IMAGES
-----------------

On Import Images you can crop, flip, and rotate before sending photos to
training or grading. Apply Changes saves the edit; Reset undoes it.

Send to Training opens Train Model and fills Step 2 with that photo folder
(you still need the labels file). Send to Grading opens Grade Images and
adds the photos to the queue.


7. MODEL LIBRARY
----------------

Each trained model is saved under models/ as a .pt (weights) and .json
(stats and history). Cards show architecture, val MAE, and test MAE when
available. Retrain continues that checkpoint on a new labelled dataset
(Train Model page) and writes a new file.

Load Model sets it for grading. Delete removes that model for good.


8. READING RESULTS
------------------

MAE (±X%) is the average absolute error vs lab labels on the validation
or test set. Smaller is better. Compare across your own models rather
than chasing a universal "good" number.

Sum check: how far Water+Solids+Bitumen is from 100%. Under ~2% is
tight; over ~5% means treat that photo carefully (bad lighting, odd
crop, etc.).

If MAE is high: more/varied photos, cleaner labels, longer training, or
crop backgrounds. See the settings above.


9. TROUBLESHOOTING
------------------

  Won't start
    Check Python version, then: pip install -r requirements.txt

  Model won't load
    File may be missing or moved. Retrain or load another from the library.

  Training fails
    Check the progress log. If you run out of memory, close other apps.

  High MAE / weird grades
    Check CSV values, add more photos, raise epochs, improve framing.

  Import fails
    Use JPG/PNG/TIF. Broken files are skipped with a message.
